## 3×3 매트릭스 (W_macro)

```
VIX:   Low(<20) / Mod(20~30) / High(≥30)
US10Y: Low(<3.5%) / Mod(3.5~4.5%) / High(≥4.5%)
```

|  | US10Y Low | US10Y Mod | US10Y High |
|---|---|---|---|
| VIX Low | 1.0 (초위험선호) | 0.8 | **0.5 (중립)** |
| VIX Mod | 0.7 | 0.5 | 0.3 |
| VIX High | 0.3 | 0.2 | 0.0 |

```
equity_pct = equity_min + (equity_max − equity_min) × W_macro
           = 100 + 50 × W_macro     (적극투자형)
cash_pct   = 100 − equity_pct        (음수 = 신용매수)
```

## 5팩터 (섹터중립 z-score, ±5σ winsor)

| # | 팩터 | 산식 |
|---|---|---|
| 1 | **밸류** | mean(z(−PER), z(−PBR), z(−EV/EBITDA)) |
| 2 | **퀄리티** | z(ROE + ROA − 부채/100 + 영익률) |
| 3 | **목표가↑(1M)** | z((TP_now/TP_1M − 1) × 100), TP = 종가×(1+괴리율/100) |
| 4 | **Fwd ROE↑(1M)** | z((ROE_F12M_now / ROE_F12M_1M − 1) × 100) |
| 5 | **거래대금↑(3M→1M, v4 회전율 기반)** | 일별 회전율=거래대금/시총. z((recent_1M 평균 회전율 / prior_1M 평균 회전율 − 1) × 100) |

## 5점 평가 + 4분류

```
5점 (각 0-5, 총 25):
  · Durability (구조적 지속성)
  · Capital Inflow (자금 유입)
  · Verifiability (실적 검증 가능성)
  · Earliness (초기성)
  · Policy Momentum (정책)

4분류:
  · 핵심 장기 테마 후보  : total ≥18 AND 모든 ≥3 AND Durability ≥4
  · 관찰 리스트         : 13~17점 OR (≥18인데 Durability<4)
  · 검증 부족           : Earliness ≥4 AND (Capital ≤2 OR Verifiability ≤2)
  · 아직 약한 아이디어    : total <10 OR Durability ≤1
```

## 편입 비중 자동 산출 (recompute_allocation.py)

```
weighted_score = total × category_multiplier
  핵심: 1.5 / 관찰: 1.0 / 검증부족: 0.5 / 약함: 0
allocation_pct = (weighted / Σ) × 90    # uncovered 10% 고정
매칭 0건 = 0%
```

# 7단계 — 포트폴리오 구성

## 에이전트: `portfolio-optimizer`
**4단계 비중 × 5단계 매칭 × 6단계 매력도** + 1단계 투자성향 제약.

## 자동화: `python3 _workspace/07_portfolio/compose_portfolio.py`

## 산식 (option C — 사후 재분배 + v4 시총별 차등 cap)

```
1차 분배:
  For idea i:
      For ticker t in matched(i):
          weighted_score = research[t].total × intensity_factor[t.intensity]
          contrib(t,i) = (weighted/Σ) × idea_alloc(i)
          weights[t] += contrib

2차 (min_weight 미만 제거 후):
  surviving = {t: weights[t] >= min_weight}
  → surviving으로 idea_alloc 정확 보존 재분배

3차 제약 강제:
  · max_single_stock_pct → 시총별 차등 cap 적용 (v4 NEW):
      - 대형(시총 ≥ 1조원)       : min(15%, max_single)
      - 중형(1천억 ≤ 시총 < 1조) : min(10%, max_single)
      - 소형(시총 < 1천억)       : min(5%, max_single)
  · 초과분 매력도 비례로 다른 종목에 재분배 (받는 종목도 자신의 cap 한도 내)
  · 반복: 모든 종목이 시총별 cap 이내가 될 때까지 (max 50회)
  · max_sector_pct → 섹터 비례 축소
  · 자본 대비 = weight × allocation.equity_pct / 100
```
